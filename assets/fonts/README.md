# Export fonts

Static TTF instances of **Inter** (SIL Open Font License 1.1, https://rsms.me/inter/) used only by the
FFmpeg/libass caption export. Generated by `scripts/build-export-fonts.mjs` from the `@fontsource/inter`
static latin weights; each weight has a unique family name (`Inter W400` … `Inter W900`). The browser
preview uses the self-hosted variable font in `src/app/fonts/`. Latin glyphs only.
